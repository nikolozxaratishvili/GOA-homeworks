CSS და JAVASCRIPT

CSS

CSS არის ენა, რომელიც გამოიყენება ვებგვერდის ვიზუალური მხარის მოსაწყობად. მისი საშუალებით ვცვლით ფერებს, ფონტებს, ზომებს და ელემენტების განლაგებას.

CSS-ის ფუნქციები:

  • ფერების და ფონის შეცვლა
  • ტექსტის ფორმატირება
  • ანიმაციების დამატება
  • დიზაინის შექმნა

JavaScript

JavaScript არის პროგრამირების ენა, რომელიც ვებგვერდებს ხდის ინტერაქტიულს. თუ HTML არის ჩონჩხი და CSS ტანსაცმელი, JavaScript არის ვებგვერდის "ტვინი".
