    • python

    Python არის თანამედროვე და პოპულარული პროგრამირების ენა, რომელიც გამოიყენება სხვადასხვა ტიპის პროგრამებისა და ვებსაიტების შესაქმნელად. იგი გამოირჩევა მარტივი სინტაქსით და ადვილად გასაგები კოდით, ამიტომ დამწყებთათვის ერთ-ერთი საუკეთესო არჩევანია. Python შეიქმნა 1991 წელს Guido van Rossum-ის მიერ.

    Python-ის გამოყენება:

    • ვებსაიტების შექმნა
    • მონაცემთა ანალიზი
    • ხელოვნური ინტელექტი (AI)
    • ბოტებისა და აპლიკაციების შექმნა
    • მონაცემების დამუშავება
    • ავტომატიზაცია

    Python-ის უპირატესობები:

    • მარტივი სასწავლია
    • კოდი მოკლე და გასაგებია
    • მუშაობს სხვადასხვა ოპერაციულ სისტემაზე
    • აქვს ბევრი ბიბლიოთეკა და ფუნქცია
    • ძალიან პოპულარულია მთელ მსოფლიოში

    Python დღეს გამოიყენება ბევრ დიდ კომპანიაში, მაგალითად Google, YouTube და Instagram.

    HTML

    HTML არის ვებსაიტების შექმნისძირითადი მარკირების ენა. მისი დახმარებით ვქმნით ვებგვერდის სტრუქტურას — სათაურებს, ტექსტებს, სურათებს და სხვა ელემენტებს.

    HTML-ის მთავარი მახასიათებლები:

    • მარტივი და ადვილად სასწავლია
    • მუშაობს ყველა ბრაუზერში
    • გამოიყენება ყველა ვებსაიტზე
    • ქმნის საიტის სტრუქტურას

    HTML-ში გამოყენებული ძირითადი თეგები:

    • h1 - სათაური
    • p - პარაგრაფი
    • img - სურათი
    • a - ლინკი
    • button - ღილაკი
    • table - ცხრილი

    HTML-ის გამოყენება:

    • ვებსაიტების შექმნა
    • ფორმების დამატება
    • ტექსტისა და სურათების განთავსება
    • ვიდეოებისა და აუდიოს ჩასმა
    • მენიუსა და ლინკების შექმნა

    HTML შეიქმნა 1993 წელს Tim Berners-Lee-ის მიერ და დღემდე ყველა ვებსაიტის საფუძველია.
