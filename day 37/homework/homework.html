CSS Selector-ები

Tag Selector ირჩევს HTML ელემენტს მისი თეგის სახელით. მაგალითი: p { color: blue; }

Class Selector ირჩევს ელემენტებს class ატრიბუტის მიხედვით. მაგალითი: .box { background-color: lightgray; }

ID Selector ირჩევს ერთ კონკრეტულ ელემენტს id ატრიბუტის მიხედვით. მაგალითი: #title { color: red; }
